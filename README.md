# Hi, I'm Siem

I build small tools that answer my own everyday questions, mostly in Python with
a bit of JavaScript, and run them on a Raspberry Pi at home.

### Public projects

- **[podium-watcher](https://github.com/siemhoukes/podium-watcher)**: tracks
  last-minute youth and student theatre deals around Tilburg, and forecasts which
  shows will still have seats when the discount window opens.
- **[vogelspoor](https://github.com/siemhoukes/vogelspoor)**: geotags bird
  photos from the GPX track of your watch. A single Windows app with a Dutch UI.
- **[knmi-weather](https://github.com/siemhoukes/knmi-weather)**: pulls KNMI
  weather data per station, with a static dashboard covering the full history
  (De Bilt back to 1901).

### Also running at home (private)

A fuel route planner that checks whether a detour abroad is worth it, a campervan
relocation monitor, a wildlife photo-spot finder built on observation records,
and a dashboard that shows what every service on the Pi is using.
